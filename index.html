设置「轻划手机收录」书签

只需设置一次，以后在网页划选文字，点书签即可收录。

  1. 点击下面的“复制手机书签代码”。
  2. 在浏览器里收藏当前页，把收藏名称改为“轻划手机收录”，再编辑它的网址，粘贴刚复制的整段代码。
  3. 重新查看书签网址，确认开头保留了 javascript:，代码完整，且没有变成搜索链接。
  4. 回到普通文章网页，先选约十个字，再点这个书签。看到“已收录”后，可用浏览器返回键继续阅读。

收集页地址：

夸克 / UC / 手机自带浏览器

一般可从菜单进入“书签 / 收藏”，先收藏本页，再在书签列表中长按该项或通过“管理 → 编辑”修改网址。菜单名字因版本不同，请以手机里的实际入口为准。请把整段代码粘到书签网址里，不是搜索框。

Safari 可使用“分享 → 添加书签”，再在书签列表中编辑网址。手机这里用网页书签，不安装桌面扩展 ZIP。

点了没反应，或总是没有选中文字？
  • 检查 javascript: 是否被删、代码是否被截断；从本页重新完整复制。
  • 先在普通资讯网页测试；浏览器首页、内置阅读页或受保护网页可能不执行脚本。
  • 如果打开书签就取消文字选区，该版本可能无法可靠使用这套流程。
  • 如果浏览器只接受 HTTP(S) 网址，或保存后总删除脚本前缀，当前版本不适用。可换允许脚本书签的浏览器，或先复制 / 分享保存。
  • 只有显示“已收录”才算保存成功；保存失败时请用“重试”或“复制这条摘录”。

夸克、UC、Via 与各品牌自带浏览器的脚本支持随版本和网页策略不同，尚未完成全部真机验收。请先做十字测试，再开始正式收集。
