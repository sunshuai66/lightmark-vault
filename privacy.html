隐私政策

本政策适用于轻划 LightMark（简称“轻划”）在 Chrome、Microsoft Edge 和 macOS Safari 上提供的桌面浏览器扩展。第八部分另说明本政策网页与手机静态收集页的访问和存储情况。

无账号摘录本机保存不上传摘录不调用 AI 接口

一、我们处理哪些信息

轻划在浏览器内处理你主动选中的网页文字、网页图片与 HTML5 视频截图、视频播放时间、视频源地址及带时间定位的网页链接、当前网页标题和网址、收录时间，以及你创建的项目名称、当前项目和语言设置。检测文字选区、定位图片或视频、显示收录浮标所需的临时信息也在浏览器内处理。

摘录的持久保存由你的收录操作触发，例如点击“收进轻划”浮标、使用收录快捷键，或使用配套收录书签。当前版本没有读取或遍历完整浏览历史的业务逻辑，也不会自动抓取整张网页存档。

二、用途与保存位置

这些信息用于保存文字、图片和视频截图、按项目查看、附加可点击来源和播放时间，以及生成 Word（.docx）或 Markdown（.md）文档。含图片的 Markdown 导出为 ZIP，内含文档和图片文件夹。图片与视频帧保存在本地数据库中；完整视频仅在你主动点击下载后由浏览器保存到设备，不写入摘录数据库或导出文档。

桌面扩展的摘录保存在当前浏览器的 IndexedDB 中，项目设置保存在浏览器本地存储中。不同浏览器、不同设备，以及桌面扩展与手机网页收集箱之间不会自动同步。

三、信息传输与第三方

当前桌面扩展不把摘录、项目或使用行为主动传送给发布者或第三方服务器，不调用第三方 AI 接口，不集成广告、用户分析或追踪服务。扩展运行代码和品牌图标随安装包提供。

你主动收录图片时，扩展可能请求媒体原始地址以获取该图片；你主动下载视频时，浏览器会请求其视频源地址。媒体所在网站可能接收必要的网络访问信息（例如 IP 地址和资源路径），适用该网站自身的隐私规则。轻划不会把已有收集箱内容附带上传到媒体网站。你主动点击来源或时间定位链接时，浏览器也会访问对应网站。你主动导出的文档由浏览器保存到设备上的下载位置；之后自行把文档发送给他人或保存到云盘，属于你自主进行的操作。

四、权限与用户控制

网站访问权限用于在获准的普通网页展示选区或媒体浮标、响应主动收录操作、读取当前网页来源信息，以及在收录原图时请求图片资源。本地存储权限用于保存项目和语言设置，摘录正文、图片与视频帧保存在 IndexedDB。右键菜单权限（contextMenus）用于显示图片收录、视频截图和视频下载入口；下载权限（downloads）仅在你明确选择下载视频源文件时交给浏览器下载，不读取下载历史或无关本地文件。

你可以在浏览器的扩展管理中调整站点授权、停用或卸载轻划。当前版本没有逐条删除或账号注销界面；你可以通过浏览器提供的相应数据管理功能清理本地数据，或卸载扩展。卸载通常会移除该扩展的本地数据库，已导出的文件仍由你在设备上自行管理。

五、保留期限与本机安全

本地摘录保留到你清理数据、卸载扩展，或浏览器／系统移除相关数据为止。清理网站数据、无痕浏览结束、浏览器存储回收，以及由开发版转为不同标识的正式安装版本，都可能影响原有数据。

轻划不承诺本地数据永不丢失，也不提供当前版本的云端恢复。请在受信任的设备上使用，并定期导出重要资料；卸载或更换安装版本前先完成导出。

六、数据出售与用途限制

当前版本不出售用户数据，不把摘录用于广告、用户画像或第三方模型训练。数据仅用于向你提供本地网页收录、项目管理和文档导出功能。

七、政策更新与联系

如果未来增加账号、联网同步或统计等功能，发布者会根据实际变化更新本政策，并按适用平台的要求向用户说明。隐私相关问题、数据处理疑问或支持请求，请联系发布者 max：ssslqqtdm@gmail.com。

八、本政策网页与手机静态收集页

手机收集页把来自不同网页的摘录保存在该收集页地址、当前浏览器的 IndexedDB 中。未完成保存的记录可能暂存在当前标签页的会话存储中，以便重试。它不与桌面扩展自动同步。

书签通过收集页网址中 # 后的地址片段传递待存摘录。地址片段不随 HTTP 请求发送给托管服务器，页面会在读取时清除片段。这不是加密；浏览器历史、浏览器同步或页面本身的代码仍可能接触该片段。

访问本政策页或手机收集页时，浏览器需要向实际托管平台请求网页资源，托管平台可能按其规则处理必要的网络访问信息，例如 IP 地址、浏览器信息、请求时间和资源路径。这不等于轻划把摘录正文上传给发布者。页面没有额外接入广告或访问统计脚本。

如果部署在 Vercel 或 GitHub Pages，可分别查看 Vercel 隐私政策、GitHub 隐私声明，了解实际托管方的处理方式。
